# To-Do App with Reminder

## 📌 Description
This project is a To-Do application developed using HTML, CSS, and JavaScript. It allows users to manage tasks, set reminders, and organize daily activities.

## 🚀 Features
- User Login
- Add / Update / Delete Tasks
- Notes Section
- Due Date Reminder
- Local Storage

## 🧪 Testing
Test cases include:
- Login validation
- Task creation
- Error handling

## ⚙️ Technologies Used
- HTML
- CSS
- JavaScript
- Azure DevOps

## 📊 Project Modules
- Task Management
- Notification System
- Task Organization
- Advanced Features
